Installation

devtools::install_github("mohsaqr/Saqrmisc")
library(Saqrmisc)

Requires R ≥ 4.1.0. Core dependencies: dplyr, ggplot2, gt, tibble, tidyr, rlang, MoEClust, vcd, bootnet, qgraph.

All functions share a consistent quoted-string API: variable names are always passed as character strings. Omit Vars to auto-select all numeric variables. All table functions support format ("gt", "plain", "markdown", "latex", "kable") and show_header parameters.

Group Comparisons

compare_groups()

Supports parametric, nonparametric, and Bayesian tests, post-hoc comparisons, equivalence testing (TOST), stratified analysis, pivot tables, and within-group analysis.

Data Transformation

All transformation functions add new columns with a configurable suffix (e.g., "_c", "_z") and support group-wise operations via the group_by parameter. Each has a vectorized _vec() companion for use inside dplyr::mutate().

center()

Subtract the mean from each value. With group_by, performs group-mean centering (useful for multilevel models).

center(data, Vars, suffix = "_c", group_by = NULL)
Example: Grand-mean centering 
result <- center(mtcars, Vars = c("mpg", "hp"))
head(result$mpg_c, 5)
# Original mpg: 21.0  21.0  22.8  21.4  18.7
# Grand mean:   20.09
# Centered mpg:  0.91   0.91   2.71   1.31  -1.39

standardize()

Z-score standardization: subtract the mean and divide by the standard deviation. The result has mean = 0 and SD = 1.

standardize(data, Vars, suffix = "_z", group_by = NULL)
Example 
result <- standardize(mtcars, Vars = c("mpg"))
head(result$mpg_z, 5)
# Standardized mpg: 0.151  0.151  0.450  0.217  -0.231

scale_vars()

Flexible scaling: divide by standard deviation ("sd") or rescale to a custom range ("range", default 0–1).

scale_vars(data, Vars, method = "sd", range = c(0, 1), suffix = "_s", group_by = NULL)
ParameterDescriptionDefault
method"sd" (divide by SD) or "range" (min-max scaling)"sd"
rangeTarget range when method = "range"c(0, 1)
Example: Min-max scaling 
result <- scale_vars(mtcars, Vars = "mpg", method = "range")
head(result$mpg_s, 5)
# Scaled to [0, 1] (original range: 10.40 – 33.90)
# Min-max mpg: 0.451  0.451  0.528  0.468  0.353

reverse_code()

Reverse code items on a rating scale (e.g., Likert). Computes min + max - x. Auto-detects the scale range or accepts explicit min/max.

reverse_code(data, Vars, min = NULL, max = NULL, suffix = "_r")
Example 
df <- data.frame(item1 = c(1, 2, 3, 4, 5))
result <- reverse_code(df, Vars = "item1", min = 1, max = 5)
# Original: 1  2  3  4  5
# Reversed: 5  4  3  2  1

Data Diagnostics

missing_analysis()

Comprehensive missing data diagnostics: per-variable counts and percentages, missing data patterns, Little's MCAR test (tests whether data is missing completely at random), and a visualization of missing patterns.

result$mcar      # Little's MCAR test

AI Interpretation

pass()

Pipe any R output — test results, model summaries, tables — to an AI model for scientific interpretation. Supports multiple providers, actions, writing styles, and output formats. Generates publication-ready Methods & Results sections with APA formatting.

pass(result, action = "interpret", style = "scientific", output = "text", provider = "openai", model = NULL, context = NULL, system_message = NULL, prompt = NULL, base_url = NULL)
ParameterOptionsDefault
action"interpret" · "explain" · "write" · "summarize" · "critique" · "suggest""interpret"
style"scientific" (APA) · "simple" · "detailed" · "brief""scientific"
output"text" · "markdown" · "latex" · "html""text"
provider"openai" · "anthropic" · "gemini" · "openrouter" · or use base_url for local models"openai"
contextStudy context string, e.g. "RCT comparing drug vs placebo, N=200"NULL
Example: Interpret a t-test 
t.test(mpg ~ am, data = mtcars) |> pass()

       context = "Automotive fuel efficiency study")
