Installation

# From CRAN
install.packages("cograph")

# Development version from GitHub
devtools::install_github("sonsoleslp/cograph")
library(cograph)

Requires R ≥ 4.4.0. Core imports: R6, grid, grDevices, ggplot2. Optional: igraph, network, qgraph, tna, scales, RColorBrewer, colorspace.

cograph accepts adjacency matrices, edge lists, igraph objects, statnet network objects, qgraph objects, or tna objects and creates publication-ready network visualizations. All functions support a pipe-friendly workflow using the sn_* family.

Quick workflow example 
# The pipe-friendly workflow
adj <- matrix(c(0, 1, 1, 1, 0, 1, 1, 1, 0), nrow = 3)

cograph(adj, layout = "circle") |>
  sn_nodes(fill = "steelblue", size = 0.08) |>
  sn_edges(color = "weight", width = "weight") |>
  sn_theme("minimal") |>
  sn_palette("viridis") |>
  splot()

# Or go directly
splot(adj, layout = "circle", node_fill = "steelblue")

Core Functions

cograph()

The main entry point. Accepts adjacency matrices, edge lists, igraph, statnet network, qgraph, or tna objects and creates a visualization-ready network object.

cograph(input, layout = "spring", directed = NULL, node_labels = NULL, seed = 42, ...)
ParameterDescriptionDefault
inputSquare matrix, edge list data frame, igraph, statnet, qgraph, or tna object—
layout"spring", "circle", "groups", "grid", "random", "star", "bipartite", "custom""spring"
directedForce directed interpretation. NULL for auto-detectNULL
node_labelsCharacter vector of node labelsNULL
seedRandom seed for deterministic layouts. NULL for random42
Returns: A cograph_network object that can be further customized and rendered.
Example: From adjacency matrix 
# From adjacency matrix
adj <- matrix(c(0, 1, 1, 1, 0, 1, 1, 1, 0), nrow = 3)
cograph(adj)

# From edge list
edges <- data.frame(from = c(1, 1, 2), to = c(2, 3, 3))
cograph(edges)

# Pipe-friendly workflow
adj <- matrix(c(0, 1, 1, 1, 0, 1, 1, 1, 0), nrow = 3)
cograph(adj, layout = "circle") |>
  sn_nodes(fill = "steelblue") |>
  sn_edges(color = "gray50") |>
  splot()
Example: Weighted network 
# Weighted network with automatic styling
w_adj <- matrix(c(0, 0.5, -0.3, 0.5, 0, 0.4, -0.3, 0.4, 0), nrow = 3)
cograph(w_adj) |>
  sn_edges(color = "weight", width = "weight") |>
  splot()

as_cograph()

Creates a lightweight cograph_network object from various network inputs. The resulting object is a named list with all data accessible via $.

as_cograph(x, directed = NULL, ...)
ParameterDescriptionDefault
xSquare matrix, edge list data frame, igraph, statnet, qgraph, tna, or existing cograph_network object—
directedForce directed interpretation. NULL for auto-detectNULL
Returns: A cograph_network named list with $from, $to, $weight, $nodes, $directed, $n_nodes, $n_edges, $labels, $source, $layout.
Example: Direct $ access 
mat <- matrix(c(0, 1, 1, 1, 0, 1, 1, 1, 0), nrow = 3)
net <- as_cograph(mat)

# Direct $ access to all data
net$from       # edge sources
net$to         # edge targets
net$weight     # edge weights
net$nodes      # nodes data frame
net$directed   # TRUE/FALSE
net$n_nodes    # 3
net$n_edges    # 3

# Getter functions
get_nodes(net)   # nodes data frame
get_edges(net)   # edges data frame
get_labels(net)  # character vector of labels
n_nodes(net)     # 3
is_directed(net) # FALSE (symmetric matrix)

# Setter functions
net <- set_nodes(net, data.frame(id = 1:3, label = c("A", "B", "C")))
net <- set_edges(net, data.frame(from = c(1,2), to = c(2,3), weight = c(0.5, 0.8)))
net <- set_layout(net, data.frame(x = c(0, 1, 0.5), y = c(0, 0, 1)))

from_qgraph()

Convert a qgraph object to cograph parameters. Extracts the network, layout, and all relevant arguments from a qgraph object and passes them to a cograph plotting engine.

from_qgraph(qgraph_object, engine = c("splot", "soplot"), plot = TRUE, weight_digits = 2, show_zero_edges = FALSE, ...)
ParameterDescriptionDefault
qgraph_objectReturn value of qgraph::qgraph()—
engine"splot" (base R) or "soplot" (grid)"splot"
plotImmediately plot the resultTRUE
weight_digitsDecimal places to round edge weights2
show_zero_edgesKeep edges that round to zeroFALSE
Returns: Invisibly, a named list of cograph parameters passable to splot() or soplot().
Parameter mapping (qgraph → cograph)

Node properties: labels/names → labels, color → node_fill, width → node_size (1.3x), shape → node_shape, border.color → node_border_color, label.cex → label_size

Edge properties: labels → edge_labels, label.cex → edge_label_size (0.5x), lty → edge_style, curve → curvature, asize → arrow_size (0.3x)

Graph properties: minimum → threshold, maximum → maximum, groups → groups, posCol/negCol → edge_positive_color/edge_negative_color

Pie/Donut: pie values → donut_fill with donut_inner_ratio=0.8, pieColor → donut_color

Note: edge_color and edge_width are NOT extracted because qgraph bakes cut-based fading into these vectors. Layout coordinates are preserved with rescale=FALSE.
Example 
library(qgraph)
adj <- matrix(c(0, .5, .3, .5, 0, .4, .3, .4, 0), 3, 3)
q <- qgraph(adj)
from_qgraph(q)  # Plots with splot

# Use soplot engine instead
from_qgraph(q, engine = "soplot")

# Override extracted parameters
from_qgraph(q, node_fill = "steelblue", layout = "circle")

# Extract parameters without plotting
params <- from_qgraph(q, plot = FALSE)

from_tna()

Convert a tna object to cograph parameters. Extracts the transition matrix, labels, and initial state probabilities, mapping initial probabilities to donut fills.

from_tna(tna_object, engine = c("splot", "soplot"), plot = TRUE, weight_digits = 2, show_zero_edges = FALSE, ...)
ParameterDescriptionDefault
tna_objectA tna object from tna::tna()—
engine"splot" or "soplot""splot"
plotImmediately plot the resultTRUE
Returns: Invisibly, a named list of cograph parameters.
TNA visual defaults

These defaults are applied for TNA plots (all overridable):

  • layout = "oval" — Oval/elliptical node arrangement
  • node_size = 7 — Larger nodes for readability
  • arrow_size = 0.61 — Prominent directional arrows
  • edge_color = "#003355" — Dark blue edges
  • edge_labels = TRUE — Show transition weights
  • edge_start_style = "dotted" — Dotted line at edge source

Pipe API (sn_* Functions)

The sn_* family provides a chainable, pipe-friendly API for building network visualizations step by step. All functions accept a cograph_network object (or raw matrix/igraph, which is auto-converted) and return a modified cograph_network.

Pipe workflow example 
adj <- matrix(c(0, 0.5, -0.3, 0.5, 0, 0.4, -0.3, 0.4, 0), nrow = 3)

cograph(adj) |>
  sn_nodes(
    size = c(0.08, 0.06, 0.1),
    fill = c("red", "blue", "green"),
    shape = "circle"
  ) |>
  sn_edges(
    color = "weight",
    width = "weight",
    edge_positive_color = "darkblue",
    edge_negative_color = "darkred"
  ) |>
  sn_layout("circle") |>
  sn_theme("minimal") |>
  sn_palette("viridis") |>
  splot()

# Or save to file
cograph(adj) |>
  sn_nodes(fill = "steelblue") |>
  sn_save("network.pdf", width = 7, height = 7)

Plotting Engines

cograph provides two rendering engines with identical parameter interfaces. Choose based on your workflow:

  • splot() — Base R graphics. Faster for large networks, good for interactive exploration
  • soplot() — Grid graphics. Better for ggplot2 integration, combining plots, and publication vector graphics
