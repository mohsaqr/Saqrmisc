# Plot Method for Clustering Results

Plot Method for Clustering Results

## Usage

``` r
# S3 method for class 'saqr_clustering'
plot(x, type = "clusters", ...)
```

## Arguments

- x:

  A \`saqr_clustering\` object from \[clustering()\].

- type:

  Plot types and/or groups; see \[plot_clustering()\].

- ...:

  Passed to \[plot_clustering()\].

## Value

\`x\`, invisibly.
