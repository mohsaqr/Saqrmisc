# Print Several Clustering Plots

Print Several Clustering Plots

## Usage

``` r
# S3 method for class 'saqr_plots'
print(x, ...)
```

## Arguments

- x:

  A \`saqr_plots\` list from \[plot_clustering()\].

- ...:

  Ignored.

## Value

\`x\`, invisibly. Called for the side effect of drawing each plot.
